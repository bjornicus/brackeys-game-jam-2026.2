# Placeholder sprite sheets

These PNGs are deterministic programmer art generated by `tools/generate_placeholder_sprites.py` and are intended to be replaced by production art later. Regenerate them from the repository root with:

```bash
python3 tools/generate_placeholder_sprites.py
```

The generator uses only the Python standard library; no runtime or Cargo dependency is required.

## `character_placeholder.png`

- Image size: 256 × 768 px.
- Grid: 4 columns × 12 rows.
- Cell size: 64 × 64 px.
- Origin convention: the gameplay `Transform` is the visual/cell center. The existing feet collider is offset downward in code.
- Row layout: rows are grouped by facing, with three state rows per facing.
  - Right: idle row 0, move row 1, shoot row 2.
  - Left: idle row 3, move row 4, shoot row 5.
  - Up: idle row 6, move row 7, shoot row 8.
  - Down: idle row 9, move row 10, shoot row 11.
- Frame ranges:
  - Idle: columns 0..2 are used; columns 2..4 may remain unused padding.
  - Move: columns 0..4 are used.
  - Shoot: columns 0..4 are used.
- Replacement expectations: keep the same dimensions, grid, row ordering, and frame counts unless the constants in `src/game.rs` are updated at the same time.

## `enemy_placeholder.png`

- Image size: 256 × 256 px.
- Grid: 4 columns × 4 rows.
- Cell size: 64 × 64 px.
- Origin convention: future enemy entities should spawn at the cell center on map tile centers; feet and hitbox offsets will be defined in gameplay code.
- Row/frame layout:
  - Row 0: idle, columns 0..4.
  - Row 1: move, columns 0..4.
  - Row 2: stunned, columns 0..4.
  - Row 3: death, columns 0..4.
- Replacement expectations: preserve this stable frame layout so later enemy animation constants remain valid.
